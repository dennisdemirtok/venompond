# Venom Pond

A playable demo of **Venom Pond**, a 5x3 slot concept with a living, animated bioluminescent swamp. Demo credits only, no real money.

## What is in the demo
- **Tongue Strike**: dragonflies fly in and the frog's tongue turns symbols into wilds.
- **Super Frog**: three wilds in a row launch a giant golden frog that turns two reels wild, with a x2 multiplier.
- **Croc Chomp** and **Venom Rain**: random events that upgrade symbols.
- **Dragonfly Hunt**: a meter with a halfway reward, then 7 Free Spins with sticky wilds.
- **Pond Hoppin'**: a risk-ladder bonus where the player collects or pushes on, with the odds shown at every step.
- Big, Mega and Epic win celebrations.

## Try it
Open `index.html` in a browser (Chrome recommended), or visit the GitHub Pages link of this repository. Press SPACE or the SPIN button. The buttons at the bottom force each feature so it can be reviewed quickly. The **i** button explains the rules and the pay table.

## Notes
- All art is original. Math in the demo is a simulated placeholder (about 95 percent RTP) and not certified.
- Work in progress, built as a concept for an OpenRGS partnership discussion.
